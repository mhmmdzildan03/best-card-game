Emberfall Duel is an original turn-based card duel against the Ash Warden: summon suit-bound Spirits, chain matching suits to trigger Bond bonuses, and out-read an AI that hunts your strongest Spirit. First hero to 0 Life loses; an empty deck brings escalating fatigue.
## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
To play: serve game/ with any static server, e.g. `python3 -m http.server -d game 8080`, then open the page it serves in a browser.
